# TDT Directo

App web de canales de la TDT: logo de cada canal, reproducción dentro de la app, cambio de canal con el mando (CH+/CH−, flechas, números) y numeración editable.

- **index.html** — la app. Ábrela en el navegador del PC, móvil o Smart TV.
- **tdt-directo.m3u8** — lista de canales para VLC, Kodi o cualquier app IPTV.
- **enlaces-m3u8.txt** — los enlaces en texto.

Los enlaces se actualizan solos al abrir la app (lista pública de TDTChannels). La numeración y los cambios que hagas se guardan en tu navegador.
